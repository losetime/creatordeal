# PayPal 订阅集成计划

## 目标
实现 PayPal Subscriptions API 集成，支持：
- 月度自动续订
- 用户取消订阅
- Webhook 自动回调（订阅激活、续订、取消、支付失败）

## 架构设计

```
用户点击 "Subscribe" → 前端调用 /api/paypal/subscribe
         ↓
后端调用 PayPal API 创建订阅 → 返回 approval_url
         ↓
用户在 PayPal 完成支付 → PayPal 发送 webhook
         ↓
Webhook 处理：激活订阅 → 更新用户 profile
         ↓
每月自动扣款 → PayPal 发送 webhook → 续订成功
         ↓
用户点击 "Cancel" → 调用 /api/paypal/cancel → 取消订阅
```

## 需要新增的文件

### 1. PayPal SDK 封装
**文件**: `lib/paypal.ts`
- 使用 `@paypal/paypal-server-sdk` 包
- 封装 PayPal API 调用（创建订阅、取消订阅、查询订阅状态）
- 根据环境变量选择 sandbox 或 live 模式

### 2. 创建订阅 API
**文件**: `app/api/paypal/subscribe/route.ts`
- 接收用户请求，调用 PayPal API 创建订阅
- 返回 PayPal 的 approval_url 给前端跳转
- 记录订阅创建请求

### 3. Webhook 处理
**文件**: `app/api/paypal/webhook/route.ts`
- 接收 PayPal 的 webhook 事件
- 验证 webhook 签名（安全）
- 处理以下事件：
  - `BILLING.SUBSCRIPTION.ACTIVATED` → 激活订阅
  - `PAYMENT.SALE.COMPLETED` → 记录付款成功
  - `BILLING.SUBSCRIPTION.CANCELLED` → 取消订阅
  - `BILLING.SUBSCRIPTION.SUSPENDED` → 暂停订阅
  - `BILLING.SUBSCRIPTION.PAYMENT.FAILED` → 支付失败

### 4. 取消订阅 API
**文件**: `app/api/paypal/cancel/route.ts`
- 调用 PayPal API 取消用户订阅
- 更新用户 profile 状态

### 5. 查询订阅状态 API
**文件**: `app/api/paypal/status/route.ts`
- 查询用户当前订阅状态
- 用于前端显示

### 6. 数据库迁移
**文件**: `sql/migration-paypal-subscriptions.sql`
- 新增 `paypal_subscription_id` 字段到 profiles 表
- 新增 `paypal_payer_id` 字段

## PayPal Webhook 事件处理逻辑

### BILLING.SUBSCRIPTION.ACTIVATED
```typescript
// 用户订阅激活
await admin.from("profiles").update({
  plan: "pro",
  subscription_status: "active",
  paypal_subscription_id: subscription.id,
  paypal_payer_id: payerId,
  subscription_expires_at: nextBillingTime,
  payment_pending: false,
}).eq("paypal_subscription_id", subscription.id)
```

### PAYMENT.SALE.COMPLETED
```typescript
// 付款成功（续订）
await admin.from("profiles").update({
  subscription_expires_at: nextBillingTime,
  last_payment_at: new Date(),
}).eq("paypal_subscription_id", subscription.id)
```

### BILLING.SUBSCRIPTION.CANCELLED
```typescript
// 用户取消订阅
await admin.from("profiles").update({
  subscription_status: "cancelled",
  // 保留 pro 权益直到当前周期结束
}).eq("paypal_subscription_id", subscription.id)
```

### BILLING.SUBSCRIPTION.PAYMENT.FAILED
```typescript
// 支付失败
await admin.from("profiles").update({
  subscription_status: "payment_failed",
}).eq("paypal_subscription_id", subscription.id)
// 发送邮件通知用户
```

## 实现步骤

1. **安装 PayPal SDK**
   ```bash
   pnpm add @paypal/paypal-server-sdk
   ```

2. **创建 lib/paypal.ts**
   - 封装 PayPal 客户端初始化
   - 封装创建订阅、取消订阅、查询状态等方法

3. **创建 Webhook 处理路由**
   - 验证 webhook 签名
   - 处理各种订阅事件
   - 更新数据库

4. **创建订阅/取消 API**
   - subscribe: 创建订阅并返回 approval_url
   - cancel: 取消订阅
   - status: 查询订阅状态

5. **修改前端**
   - 添加 PayPal 按钮
   - 添加取消订阅功能
   - 显示订阅详情

6. **配置 PayPal**
   - 在 PayPal 后台创建订阅计划
   - 配置 Webhook URL
   - 获取 API 凭证

   - 创建测试订阅
   - 验证 webhook 回调
   - 测试取消订阅

2. **功能验证**
   - 用户可以成功订阅
   - 订阅状态正确显示
   - 取消订阅后状态更新
   - Webhook 正确处理各种事件

## 风险与注意事项

1. **Webhook 签名验证** - 必须验证 PayPal webhook 签名，防止伪造
2. **幂等性** - Webhook 可能重复发送，处理逻辑需要幂等
3. **错误处理** - PayPal API 调用失败时需要适当的错误处理
4. **测试环境** - 使用沙盒环境测试，避免真实扣款
