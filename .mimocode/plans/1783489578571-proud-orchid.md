# 免费 API 对接调研

## 结论：没有免费 API 直接提供"费率基准"数据

经过调研，**不存在免费的 API 能直接返回"某个平台某个粉丝量级的创作者应该收多少钱"**。费率数据是各平台/代理商的 proprietary 数据，不会公开提供。

---

## 可用的免费/低成本数据源

### 1. YouTube Data API v3（免费）
- **提供**：频道订阅数、视频播放量、视频数量
- **不提供**：报价/费率
- **免费额度**：每天 10,000 单位
- **用途**：可以获取频道真实数据，用于粉丝层级分类
- **接入成本**：零

### 2. Instagram Graph API（免费）
- **提供**：自己的商业/创作者账号数据（粉丝数、互动率）
- **不提供**：其他创作者的数据，也不提供费率
- **限制**：只能获取自己授权账号的数据
- **用途**：验证用户声称的粉丝数是否属实

### 3. TikTok Research API（免费但受限）
- **提供**：公开视频数据、话题趋势
- **限制**：仅限学术机构，需申请
- **不提供**：费率数据

### 4. Social Blade（无官方 API）
- 有第三方封装库，但不稳定
- 数据包括粉丝增长、视频排名
- 不提供费率

---

## 实际可行的方案

### 方案 A：基于社交数据 + 公式估算（推荐）

**原理**：不直接获取费率，而是获取真实社交数据后用公式估算合理报价。

```
估算费率 = 粉丝数 × CPM系数 × 互动率系数 × 内容类型系数
```

- CPM系数：基于行业平均 CPM（如 YouTube $5-15 CPM）
- 互动率系数：高互动率可提高报价
- 内容类型系数：Video > Reel > Story > Post

**优点**：
- 可以用免费的 YouTube/Instagram API 获取真实数据
- 公式可配置，灵活调整
- 不依赖付费 API

**缺点**：
- 估算值不如真实报价准确
- 需要维护公式参数

### 方案 B：众包数据（已实现）

**原理**：用户保存自己的报价，系统聚合后显示市场分布。

- 已有 `refreshAggregates` 机制
- 需要用户积累到一定量（≥30条）才有意义
- 最终会成为最有价值的数据

### 方案 C：静态基准 + 手动更新（当前方案）

**原理**：基于行业报告的静态数据，定期手动更新。

- 当前已有 30 条数据
- 每年根据 Influencer Marketing Hub 等报告更新一次
- 简单可靠，但会过时

---

## 建议

**短期**：保持方案 C（静态基准），够用

**中期**：实现方案 A（公式估算），用 YouTube Data API 获取真实粉丝数/互动率，结合公式给出更精确的估算

**长期**：方案 B（众包数据）积累到一定量后，成为最有价值的数据源

## 如果要实现方案 A

### 需要改动的文件

| 文件 | 改动 |
|------|------|
| `lib/trpc/routers/rates.ts` | 新增 `estimateRate` procedure，调用 YouTube API 获取频道数据，用公式计算估算费率 |
| `app/(dashboard)/rates/page.tsx` | 新增"基于真实数据估算"选项，输入 YouTube 频道 URL |
| `.env.local` | 添加 `YOUTUBE_API_KEY` |
| `sql/migration-rate-benchmarks.sql` | 无需改动 |

### 实现步骤

1. 用户输入 YouTube 频道 URL 或频道 ID
2. 后端调用 YouTube Data API 获取：订阅数、视频列表、最近视频的播放量
3. 计算互动率 = (点赞 + 评论) / 播放量
4. 根据公式估算费率
5. 与基准数据对比显示

### 公式示例

```
YouTube Video 估算费率 =
  订阅数 × $0.01 × 互动率系数 × 内容类型系数

互动率系数:
  > 5%: 1.5x
  3-5%: 1.2x
  1-3%: 1.0x
  < 1%: 0.8x

内容类型系数:
  long_video: 1.0
  short: 0.4
```
