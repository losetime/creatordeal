# PayPal 订阅轮询优化计划

## 当前实现分析

现有流程：
1. 用户点击 Subscribe → `POST /api/paypal/subscribe` 创建订阅
2. 前端重定向到 PayPal 支付页面
3. 支付完成后 PayPal 重定向回 `/subscription?subscription=success`
4. 前端开始每 2 秒轮询 `GET /api/paypal/status`
5. PayPal 发送 webhook `BILLING.SUBSCRIPTION.ACTIVATED` 更新数据库
6. 前端检测到 `status === "active"` 且 `plan === "pro"` 后停止轮询

### 现有问题

| 问题 | 影响 |
|------|------|
| 无最大重试次数 | 如果 webhook 未到达，用户会无限看到 loading |
| 无超时机制 | 用户可能永久卡在验证状态 |
| 无组件卸载清理 | 内存泄漏风险 |
| 判断条件错误 | `status === "active" \|\| plan === "pro"` 会误判，需改为 `&&` |
| Toast 重复显示 | React Strict Mode 下 useEffect 执行两次，导致提示出现两次 |
| expiresAt 为空 | webhook 可能未返回 `next_billing_time` 字段 |

## 改进方案

### 1. 修复 Toast 重复显示 (`app/(dashboard)/subscription/page.tsx`)

**问题**: `utils.profiles.get.invalidate()` 触发 profile 重新获取后，`utils` 引用变化导致 `useEffect` 重新执行，即使有 `pollingRef` 也无法阻止。

**解决方案**: 用 `toastShownRef` 跟踪 toast 是否已显示，而不是阻止 effect 重新执行：

```tsx
const pollingRef = useRef(false)
const toastShownRef = useRef(false)

useEffect(() => {
  const subscriptionStatus = searchParams.get("subscription")
  if (subscriptionStatus !== "success") {
    // ... cancelled handling
    return
  }

  // Prevent duplicate polling in Strict Mode
  if (pollingRef.current) return
  pollingRef.current = true

  setVerifying(true)
  let retryCount = 0
  const MAX_RETRIES = 10
  const POLL_INTERVAL = 2000
  let timeoutId: NodeJS.Timeout

  const checkStatus = async () => {
    try {
      const res = await fetch("/api/paypal/status")
      const data = await res.json()

      if (data.hasSubscription && data.status === "active" && data.plan === "pro") {
        utils.profiles.get.invalidate()
        // Only show toast once
        if (!toastShownRef.current) {
          toastShownRef.current = true
          toast.success("Subscription activated!", { description: "Welcome to Creator Club!" })
        }
        setVerifying(false)
        window.history.replaceState({}, "", "/subscription")
        return
      }
      // ... rest of polling logic
    }
  }
  // ...
}, [searchParams, utils])
```

### 2. 修复 expiresAt 为空 (`app/api/paypal/webhook/route.ts`)

**问题**: 用户收到的是 `PAYMENT.SALE.COMPLETED` 事件，不是 `BILLING.SUBSCRIPTION.ACTIVATED`。`PAYMENT.SALE.COMPLETED` 没有 `next_billing_time` 字段。

**解决方案**: 在 `PAYMENT.SALE.COMPLETED` 处理中添加 fallback 计算：

```ts
case "PAYMENT.SALE.COMPLETED": {
  const subscriptionId = resource.billing_info?.next_billing_time
    ? resource.id
    : null

  if (subscriptionId) {
    const { data: profile } = await admin
      .from("profiles")
      .select("id")
      .eq("paypal_subscription_id", subscriptionId)
      .single()

    if (profile) {
      // 计算 30 天后的过期时间作为 fallback
      const expiresAt = resource.billing_info?.next_billing_time
        || new Date(Date.now() + 30 * 24 * 60 * 60 * 1000).toISOString()
      
      await admin
        .from("profiles")
        .update({
          subscription_expires_at: expiresAt,
          last_payment_at: new Date().toISOString(),
        })
        .eq("id", profile.id)
    }
  }
  break
}
```

### 3. 优化轮询逻辑 (`app/(dashboard)/subscription/page.tsx`)

**修改文件**: `app/(dashboard)/subscription/page.tsx` 第 24-53 行

**改进内容**:
- 添加最大重试次数（10 次 = 20 秒）
- 固定 2 秒轮询间隔
- 添加组件卸载时的清理逻辑
- 10 次后提示用户稍后重试

```tsx
// 改进后的轮询逻辑
useEffect(() => {
  const subscriptionStatus = searchParams.get("subscription")
  if (subscriptionStatus !== "success") return

  setVerifying(true)
  let retryCount = 0
  const MAX_RETRIES = 10
  const POLL_INTERVAL = 2000
  let timeoutId: NodeJS.Timeout

  const checkStatus = async () => {
    try {
      const res = await fetch("/api/paypal/status")
      const data = await res.json()
      
      if (data.hasSubscription && data.status === "active" && data.plan === "pro") {
        // 成功：订阅已激活（必须 status=active 且 plan=pro 同时满足）
        utils.profiles.get.invalidate()
        toast.success("Subscription activated!", { description: "Welcome to Creator Club!" })
        setVerifying(false)
        window.history.replaceState({}, "", "/subscription")
        return
      }

      retryCount++
      if (retryCount >= MAX_RETRIES) {
        // 超时：达到最大重试次数
        toast.error("Verification pending", {
          description: "Your payment is being processed. Please check back in a few minutes."
        })
        setVerifying(false)
        window.history.replaceState({}, "", "/subscription")
        return
      }

      // 继续轮询
      timeoutId = setTimeout(checkStatus, POLL_INTERVAL)
    } catch {
      retryCount++
      if (retryCount >= MAX_RETRIES) {
        toast.error("Verification pending", {
          description: "Your payment is being processed. Please check back in a few minutes."
        })
        setVerifying(false)
        window.history.replaceState({}, "", "/subscription")
        return
      }
      timeoutId = setTimeout(checkStatus, POLL_INTERVAL)
    }
  }

  checkStatus()

  // 清理函数
  return () => {
    if (timeoutId) clearTimeout(timeoutId)
  }
}, [searchParams, utils])
```
