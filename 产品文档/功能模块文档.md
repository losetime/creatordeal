## 1. Dashboard 仪表盘

### 1.1 数据概览卡片

| 功能 | 描述 | 交互 |
|------|------|------|
| 活跃交易数 | 显示当前进行中的交易数量（不含 paid/closed） | 点击跳转到交易列表，筛选"进行中" |
| 待收款金额 | 显示 signed/creating/review/published 阶段交易的总金额 | 点击跳转到发票列表，筛选"未付" |
| 已完成收入 | 显示 paid 阶段交易的累计收入 | 点击跳转到交易列表，筛选"已付款" |
| 未读通知数 | 显示未读通知数量 | 点击展开通知面板 |

### 1.2 交易流水线（Pipeline）

| 功能 | 描述 | 交互 |
|------|------|------|
| 看板视图 | 横向展示 8 个阶段：Inquiry → Negotiate → Signed → Creating → Review → Published → Paid → Closed | 拖拽交易卡片可切换阶段（受转换规则约束） |
| 阶段计数 | 每个阶段标题显示该阶段交易数量 | — |
| 阶段金额小计 | 每个阶段底部显示该阶段交易总金额 | — |
| 交易卡片 | 显示：交易标题、品牌 Logo、金额、截止日期 | 点击跳转到交易详情页 |
| 空状态 | 无交易时显示插图 + "创建第一笔交易"按钮 | 按钮打开新建交易弹窗 |

### 1.3 即将到期提醒

| 功能 | 描述 | 交互 |
|------|------|------|
| 内容截止提醒 | 显示 7 天内到期的交易（按截止日期升序） | 点击跳转到对应交易详情 |
| 支付截止提醒 | 显示 7 天内到期的待收款发票 | 点击跳转到对应发票详情 |
| 紧急标识 | 超过截止日期的项目标红显示 | — |

### 1.4 收入趋势图表

| 功能 | 描述 | 交互 |
|------|------|------|
| 月度收入折线图 | 显示近 6 个月的收入趋势 | 鼠标悬停显示具体月份金额 |
| 图例 | 标示数据含义 | — |

### 1.5 快捷操作

| 功能 | 描述 | 交互 |
|------|------|------|
| 新建交易 | 快速入口 | 点击打开新建交易弹窗 |
| 查看通知 | 快速入口 | 点击展开通知面板 |

## 2. Deals 交易管理

### 2.1 交易列表

| 功能 | 描述 | 交互 |
|------|------|------|
| 表格视图 | 显示所有交易，字段：标题、品牌、阶段、金额、内容截止、支付截止 | 点击表头可排序 |
| 搜索 | 按标题/品牌名模糊搜索 | 输入即搜，无延迟 |
| 阶段筛选 | 下拉选择器，可筛选特定阶段的交易 | 选择后立即过滤列表 |
| 品牌筛选 | 下拉选择器，可筛选特定品牌的交易 | 选择后立即过滤列表 |
| 新建按钮 | 右上角"新建交易"按钮 | 点击打开新建交易弹窗 |
| 批量操作 | 多选交易后可批量修改阶段/删除 | 勾选后显示操作栏 |

### 2.2 新建/编辑交易

| 功能 | 描述 | 交互 |
|------|------|------|
| 交易标题 | 必填，200 字符限制 | 输入框，实时字数统计 |
| 关联品牌 | 从已有品牌中选择，或新建 | 下拉搜索，可快速创建新品牌 |
| 金额 | 可选，正数 | 数字输入，支持小数点 |
| 币种 | 默认 USD，下拉选择 | — |
| 内容类型 | 文本输入（如：Instagram Post, TikTok Video） | 输入框 |
| 内容截止日期 | 可选 | 日期选择器 |
| 支付截止日期 | 可选 | 日期选择器 |
| 支付条款 | 文本输入 | 多行输入框 |
| 备注 | 可选 | 多行输入框 |
| 保存 | 保存交易 | 点击保存，关闭弹窗，列表刷新 |

### 2.3 交易详情

| 功能 | 描述 | 交互 |
|------|------|------|
| 基本信息 | 显示交易所有字段 | 点击编辑图标可内联编辑 |
| 阶段流转 | 显示当前阶段和可流转的下一阶段 | 下拉选择新阶段，自动流转 |
| 阶段历史 | 显示阶段变更历史时间线 | — |

#### 2.3.1 交付物管理

| 功能 | 描述 | 交互 |
|------|------|------|
| 交付物列表 | 显示该交易下的所有交付物 | 表格展示 |
| 新建交付物 | 类型、描述、数量、截止日期 | 点击"添加"打开表单 |
| 更新状态 | pending → in_progress → submitted → approved/rejected | 下拉选择状态 |
| 删除交付物 | 删除单个交付物 | 确认后删除 |

#### 2.3.2 合同管理

| 功能 | 描述 | 交互 |
|------|------|------|
| 合同列表 | 显示该交易关联的合同 | 卡片/列表展示 |
| 上传合同 | 上传 PDF/Word 文件 | 拖拽或点击上传 |
| AI 分析摘要 | 自动生成合同摘要 | 上传后自动触发 |
| 风险提示 | 高亮合同风险条款 | AI 识别后展示 |
| 关键条款 | 提取付款条款、使用期限等 | AI 识别后展示 |
| 使用权限 | 提取内容使用权限信息 | AI 识别后展示 |

#### 2.3.3 发票管理（交易维度）

| 功能 | 描述 | 交互 |
|------|------|------|
| 该交易的发票列表 | 显示关联发票 | 表格展示 |
| 新建发票 | 金额、截止日期、备注 | 点击"新建发票"打开表单 |
| 发票编号 | 系统自动生成（格式：INV-YYYYMM-XXX） | — |

### 2.4 交易阶段流转规则

| 当前阶段 | 可流转至 |
|----------|----------|
| inquiry | negotiate, closed |
| negotiate | signed, closed |
| signed | creating |
| creating | review |
| review | published, creating |
| published | paid, closed |
| paid | closed |
| closed | （终态，不可流转） |

### 2.5 交易删除

| 功能 | 描述 | 交互 |
|------|------|------|
| 删除交易 | 删除交易及其所有关联数据（交付物、合同、发票） | 二次确认弹窗 |
| 批量删除 | 多选后批量删除 | 确认后批量执行 |

## 3. Invoices 发票管理

### 3.1 发票列表

| 功能 | 描述 | 交互 |

| 表格视图 | 显示所有发票，字段：发票号、交易、品牌、金额、状态、截止日期、创建时间 | 点击表头可排序 |

| 状态筛选 | 下拉选择：All/Draft/Sent/Viewed/Paid/Overdue/Cancelled | 选择后立即过滤 |
| 金额汇总 | 列表底部显示筛选结果的总金额 | — |
| 新建按钮 | 右上角"新建发票"按钮 | 点击打开新建发票弹窗 |

### 3.2 新建/编辑发票

| 功能 | 描述 | 交互 |
|------|------|------|
| 关联交易 | 从已有交易中选择（必填） | 下拉搜索选择 |
| 金额 | 正数（必填） | 数字输入，支持小数点 |
| 币种 | 默认 USD | 下拉选择 |
| 截止日期 | 必填 | 日期选择器 |
| 备注 | 可选 | 多行输入框 |
| 保存 | 保存发票 | 点击保存，关闭弹窗 |

### 3.3 发票详情

| 功能 | 描述 | 交互 |
|------|------|------|
| 发票信息 | 显示发票号、金额、状态、截止日期等 | 点击编辑图标可修改 |
| 关联交易 | 显示交易标题、品牌名称 | 点击跳转到交易详情 |
| 状态变更 | 显示当前状态和可流转的下一状态 | 下拉选择新状态 |
| 收款记录 | 显示该发票的所有收款记录 | 时间线展示 |
| 导出 PDF | 生成发票 PDF 文件 | 点击下载/预览 |
| 发送发票 | 标记发票为已发送 | 点击确认后状态变更 |

### 3.4 发票状态流转规则

| 当前状态 | 可流转至 |
|----------|----------|
| draft | sent, cancelled |
| sent | viewed, paid, overdue, cancelled |
| viewed | paid, overdue, cancelled |
| partial | paid, overdue, cancelled |
| overdue | paid, cancelled |
| paid | （终态） |
| cancelled | （终态） |

### 3.5 超期检查

| 功能 | 描述 | 交互 |
|------|------|------|
| 自动检测 | 系统定时检查已发送/已查看但未支付且超过截止日期的发票 | 自动将状态更新为 overdue |
| 超期通知 | 超期时自动发送系统通知 | 通知中心显示 |

## 4. Payments 收款管理

### 4.1 收款列表

| 功能 | 描述 | 交互 |
|------|------|------|
| 表格视图 | 显示所有收款记录，字段：发票号、交易、品牌、金额、支付方式、支付时间 | 点击表头可排序 |
| 搜索 | 按发票号/交易标题/品牌名搜索 | 输入即搜 |
| 时间筛选 | 按时间段筛选（本月/本季/本年/自定义） | 日期范围选择器 |
| 金额汇总 | 列表底部显示筛选结果的总金额 | — |

### 4.2 记录收款

| 功能 | 描述 | 交互 |
|------|------|------|
| 关联发票 | 从未付/部分付发票中选择（必填） | 下拉搜索选择 |
| 收款金额 | 正数，不能超过发票剩余金额（必填） | 数字输入 |
| 币种 | 默认 USD | 下拉选择 |
| 支付方式 | 文本输入（如：Bank Transfer, PayPal, Stripe） | 输入框 |
| 参考编号 | 可选，交易流水号 | 输入框 |
| 备注 | 可选 | 多行输入框 |
| 确认收款 | 提交收款记录 | 点击保存，自动更新发票状态 |

### 4.3 收款逻辑

| 场景 | 处理方式 |
|------|----------|
| 全额收款 | 发票状态自动更新为 paid，交易阶段自动更新为 paid |
| 部分收款 | 发票状态更新为 partial，记录已收金额 |
| 超额收款 | 系统提示错误，不允许提交 |
| 自动通知 | 收款成功后自动发送系统通知 |
| 自动关联 | 交易在 paid 阶段时自动创建通知 |
